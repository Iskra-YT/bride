# Using Bride in C3

C3 support uses a native C3 binding module that wraps the C library. It is the
newest port and requires an extra compiler.

## Requirements

- Node.js 18+
- Emscripten SDK (`emcc`, `emar`)
- The C3 compiler (`c3c`) on your `PATH`

Both `c3c` and `emcc` are required: `bride build` first compiles the C3 sources
with `c3c`, then links the resulting objects with Emscripten.

## Create a project

```sh
mkdir my-app
cd my-app
npm install bride
npx bride new c3
```

This copies `template/c3/` into the current directory. `package.json` must
contain `"language": "c3"`.

## Import the module

```c3
module main;

import bride;
```

Everything is accessed through the `bride::` prefix:

```c3
bride::ui
bride::change
bride::text
bride::textf
bride::p
bride::div_
bride::button
bride::on_click
```

## A complete example

`src/main.c3`:

```c3
module main;

import bride;

int count = 0;

fn void increment()
{
    count++;
    bride::change("#counter", bride::textf("Clicks: %d", count));
}

fn void main()
{
    bride::ui(
        bride::p(
            bride::id("counter"),
            bride::textf("Clicks: %d", count)
        ),
        bride::button(
            bride::text("Increment"),
            bride::on_click(&increment)
        )
    );
}
```

Notes:

- The entry point is `fn void main()` (no arguments).
- Event handlers are `fn void()` values and are passed by reference, e.g.
  `&increment`.
- `bride::textf` uses C3's string formatting.
- In C3, `var` is a keyword, so the tag is `bride::var_`.

## Routing

`bride::route(path, page)` registers a page handler that the runtime renders
when the URL matches. Handlers are `fn void()` values, passed by reference:

```c3
fn void home()
{
    bride::ui(bride::h1(bride::text("Home")));
}

fn void about()
{
    bride::ui(bride::h1(bride::text("About")));
}

fn void main()
{
    bride::route("/", &home);
    bride::route("/about", &about);
}
```

Use `bride::navigate(path)` to change pages from code. See
[Routing](api-reference.md#routing) for matching rules and details.

## Project configuration

The C3 template includes a `project.json`. The target must produce object files
for Emscripten:

```json
{
  "sources": [ "src/**" ],
  "build-dir": "dist/lib/",
  "targets": {
    "bride-app": {
      "type": "object-files",
      "target": "emscripten"
    }
  }
}
```

## Build and run

```sh
npx bride build   # c3c -> object files -> emcc link -> dist/main.wasm
npx bride dev     # serve at http://localhost:9876 with live reload
```

## Notes and conventions

- Names ending in `_` avoid clashes with keywords or libc: `div_`, `main_`,
  `time_`, `select_`, `map_`, `template_`, `var_`.
- Children and fields can appear in any order inside a tag.

See the [API reference](api-reference.md) for every tag, attribute, and event.
